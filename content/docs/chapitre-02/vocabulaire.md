## Vocabulaire du chapitre

- les cheveux (longs/courts, bruns/blonds) — hair (long/short, brown/blond)
- les yeux — the eyes
- grand(e) / petit(e) — tall / short
- mince / gros(se) — slim / heavy
- porter — to wear
- un jean, une jupe, un pull, une robe — jeans, a skirt, a sweater, a dress
- sympathique / antipathique — nice / unpleasant
- timide / bavard(e) — shy / talkative
- drôle / sérieux(se) — funny / serious
- aimer / détester — to like / to hate
- ne...pas — not

## Note culturelle

En France, les adjectifs de personnalité comme « sympa » (forme courte de « sympathique ») sont très utilisés dans la langue courante entre jeunes.
