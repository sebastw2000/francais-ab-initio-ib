## Vocabulaire du chapitre

- se réveiller / se lever — to wake up / to get up
- se laver / se doucher — to wash oneself / to shower
- s'habiller — to get dressed
- le matin / l'après-midi / le soir — morning / afternoon / evening
- la maison / l'appartement — the house / the apartment
- la chambre / la cuisine / la salle de bains — bedroom / kitchen / bathroom
- tous les jours — every day
- il est ... heures — it is ... o'clock
- aller — to go
- faire — to do / to make
- se coucher — to go to bed

## Note culturelle

En France, beaucoup de personnes prennent un petit-déjeuner rapide, et le repas principal de la journée est souvent le déjeuner ou le dîner en famille.
