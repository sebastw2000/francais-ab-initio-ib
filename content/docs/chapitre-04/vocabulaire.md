## Vocabulaire du chapitre

- le petit-déjeuner / le déjeuner / le dîner — breakfast / lunch / dinner
- un repas — a meal
- la cuisine — cooking / the kitchen
- une recette — a recipe
- faire les courses — to go grocery shopping
- un supermarché — a supermarket
- un restaurant / commander — a restaurant / to order
- la carte — the menu
- le pain / le fromage — bread / cheese
- les légumes / les fruits — vegetables / fruit
- la viande / le poisson — meat / fish
- avoir faim / avoir soif — to be hungry / to be thirsty

## Note culturelle

En France, le repas est souvent un moment social important : le déjeuner et le dîner peuvent durer plus d'une heure, avec plusieurs plats (entrée, plat principal, dessert).
