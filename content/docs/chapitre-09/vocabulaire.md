## Vocabulaire du chapitre

- le lycée / un(e) élève / un professeur — high school / a student / a teacher
- une matière — a school subject
- les mathématiques / l'histoire / les sciences — math / history / science
- la récréation — recess
- un devoir / un examen — homework / an exam
- une règle / le règlement — a rule / the rules
- une activité extrascolaire — an extracurricular activity
- interdit / autorisé — forbidden / allowed

## Note culturelle

Dans le système scolaire français, le lycée dure trois ans (seconde, première, terminale) et se termine par le baccalauréat, un examen national très important.
